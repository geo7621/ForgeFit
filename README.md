# ForgeFit

ForgeFit is a dark, mobile-first fitness tracker prototype with workout plans, timers, streaks, profile-based calorie estimates, macros, food suggestions, and progress tracking.

## Android build

This repository includes a GitHub Actions workflow at `.github/workflows/build-apk.yml` that builds a debug APK and uploads it as a workflow artifact.

## Current training templates

The included routines are original, general-purpose templates (PPL, Bro Split, Upper/Lower, Full Body). They do not reproduce paid influencer programs verbatim.
